# CA-Central-Valley-commute-clustering
Using hierarchical clustering algorithms to divide California's Central Valley into commuter regions.

This repository contains the code used to generate the clusters, as well as some exploratory analysis of the clusters obtained and some extension of this process to other metro areas (Los Angeles and the Boston-Washington corridor.)

A Tableau visualization summarizing the best clustering for the Central Valley appears [https://public.tableau.com/views/DividingtheCaliforniaCentralValleybyCommutePatterns/Story1?:language=en-US&:sid=&:redirect=auth&:display_count=n&:origin=viz_share_link|here].
